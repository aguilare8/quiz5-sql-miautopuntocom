# quiz5-sql-miautopuntocom
## Contenido
- `sql/01_ddl.sql`: creación de la base de datos, tablas y restricciones (Partes 1 y 2).
- `sql/02_dml.sql`: datos de prueba (Parte 3).
- `sql/03_consultas.sql`: las 8 consultas solicitadas (Parte 4).
- `capturas/`: evidencia de la ejecución en MySQL Workbench.

## Cómo ejecutarlo
Abrir MySQL Workbench, conectarse al servidor local y ejecutar los scripts en orden: 01, 02 y 03.
